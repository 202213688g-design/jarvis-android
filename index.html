⚙ Configuración, personalidad y memoria

No pegues claves API ni contraseñas aquí. GitHub Pages es público; utiliza un servidor intermediario seguro. Sin servidor, JARVIS utiliza comandos locales.

La memoria y el historial se guardan con localStorage. No se sincronizan entre dispositivos. Al activar IA externa, tus mensajes y memoria se enviarán al servidor configurado.

Prueba: «hola», «qué hora es», «qué fecha es», «recuerda que me gusta la ciencia», «qué recuerdas de mí», «abre YouTube» o «busca astronomía».
